# StoreApi

API REST para una tienda electrónica desarrollada en .NET 8.

## Características

- CRUD de productos
- Arquitectura en capas
- LINQ y buenas prácticas
- Base de datos en memoria para pruebas
- Swagger habilitado para pruebas rápidas

## Tecnologías

- ASP.NET Core 8
- Entity Framework Core
- InMemory Database
- Swagger
